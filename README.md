# 한국형 사회정서교육 교육과정 - 플립북

GitHub Pages로 배포하는 페이지 넘김 방식 웹 뷰어입니다.

## 배포 방법 (GitHub Pages)

1. GitHub에서 새 저장소(Repository)를 만듭니다.
2. 이 폴더의 파일 전체(`index.html`, `pages/` 폴더, `.nojekyll`)를 저장소에 올립니다.
3. 저장소의 **Settings → Pages** 메뉴로 들어갑니다.
4. **Source**를 `Deploy from a branch`로 설정하고, **Branch**를 `main` / `(root)`로 선택한 뒤 저장합니다.
5. 1~2분 후 `https://사용자아이디.github.io/저장소이름/` 주소로 접속하면 바로 열립니다.
